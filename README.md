# Meesho put-to-light

Hardware for the Meesho put-to-light system (Flexli Technologies).

| Folder | Content |
|---|---|
| [`PTL-RAIL/`](PTL-RAIL/) | Modular IR TX/RX rail PCB, rev A (KiCad 10): 400 × 40 mm, 5 IR emitter/receiver nodes, ESP32-S3, CAN. See [PTL-RAIL/README.md](PTL-RAIL/README.md) for pinouts, the pin map, fab/assembly notes and known issues. |

Production files (BOM, Gerbers/drill for a 2-up panel, interactive BOM, IPC netlist, pick-and-place, refdes list, schematic PDF, KiCad source) are attached to each [GitHub release](../../releases).
